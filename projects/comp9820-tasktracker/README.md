## 可核实的个人工作

- 建立后端与数据库基础，参与任务操作、输入校验以及页面与后端的连接。
- 实现任务关键词搜索，处理输入边界，并参与搜索流程联调。
- 增加任务排序，参与状态管理、数据迁移、筛选与页面衔接。
- 整理路由、服务与数据库职责，参与回归覆盖相关改动和工程文档维护。
