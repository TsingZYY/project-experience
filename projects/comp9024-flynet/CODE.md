## 为什么本目录没有源码

保存的 COMP9024 26T2 官方作业页面明确禁止将代码放在公开可访问仓库或让他人查看解答。作品集据此仅公开项目高层描述、学习笔记与复盘；本地 `flynet.c` 不复制到此目录，也不通过补丁、附件或其他文件间接发布。

题面本身还有单独的复制发布限制，因此本目录没有题面、截图、学校样例和标准输出。

已有实现使用 C 标准库，涉及图存储、增删操作、最短路径、割点和内存管理。此处不提供恢复完整解答所需的代码、伪代码、接口细节或操作样例。
