## 项目概述

本地课程项目围绕机场与航线网络管理，涉及顶点和边的动态维护、路径查询、连接性分析与程序资源释放。公开作品集仅整理高层技术内容和可复用经验，不发布课程解答源码。

学习内容包括：

- 用图表示实体及带权连接，处理添加和删除后的索引一致性。
- 用 Dijkstra 理解正权图的最短路径与路径恢复。
- 用 DFS 的发现顺序和 low-link 信息理解割点。
- 在 C 中管理动态数组、矩阵和分配失败后的资源状态。
