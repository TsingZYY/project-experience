## 项目问题

在 51 资产的模拟交易环境中，策略需要根据当前可见的价格历史返回整数目标仓位，同时满足资产限额和运行时间约束。项目从简单收益反转逐步转向价格水平关系、稳定配对、残差信号与有限在线适应，并持续检查选模与验证是否使用了相同窗口。

## 可核实的历史产物

- 最终本地验证报告记录：五个公开窗口中，38,505 个仓位元素与原 V10 全部一致。
- 同一系列报告记录：合成前缀从第 130 天推进至第 2,000 天，共 1,871 次调用，当时本机耗时 63.93 秒，未出现记录中的仓位或数值校验失败。
- V10-O2 在公开第 751—1,000 天、1×成本回放中的 Score 为 815.562974；五个公开窗口的平均 Score 为 872.917775。

这些是指定代码、机器和公开数据口径下的历史记录。V10 在完整公开历史出现后形成，因此相关回放不构成完全隔离的样本外结果，也没有据此确认真实交易收益或隐藏排行榜名次。
