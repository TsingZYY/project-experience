## 项目内容

将两个文本文件之间的变化建模为添加、删除和替换命令。程序解析命令格式、检查位置关系、验证它们能否解释文件变化，并通过最长公共子序列（LCS）寻找和枚举差异表示。

当前源文件包含三个主要接口：

- `DiffCommandsError`：报告无效命令。
- `DiffCommands`：读取命令文件、解析与检查命令，输出规范文本形式。
- `OriginalNewFiles`：读取原文件和新文件，验证及展示差异，生成不同最优差异命令。
