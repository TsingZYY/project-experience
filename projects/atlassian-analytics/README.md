## 目标与交付

把分散的客户、产品使用和工单记录转化为可追查的复核依据，研究哪些信号值得进一步核实。交付包含数据分析、来源证据卡、最小规则模型和展示材料；真实客服干预仍属后续工作。

## 可核实成果

- 连接8,320名客户、8,469张工单和42,210条产品使用记录，检查身份、时间、重复键和历史完整性。
- 客户级套餐与集成使用量的样本关联η²约0.8793；1,666名留出客户上R²约0.8726。这些关联不能解释为升级或收入效果。
- 独立审计文件记录459项检查通过。固定的12项工单／集成比较经Holm校正后，没有获得清晰支持的关系。
- 规则为全部工单输出三类结果：347张数据待核对、43张人工复核候选、8,079张常规支持。
- 形成分析报告及10页英文展示材料。演示文件未重复收录到本目录。
