## 研究问题

当整体误接受率相近时，验证器错误在任务之间的结构是否会改变模型利用错误奖励及迁移到新任务的风险？这是待检验问题；当前项目没有建立完整的跨任务因果结论。

## 已完成的工作

- 整理文献与证据类型，设计可控算术任务、对照和实验前置条件。
- 建立冻结协议、数据／文件清单、验证程序及执行回执。
- 通过 R10 无模型开发诊断发现原统一共享潜在身份解释不成立，据此收窄后续假设。
- 准备 R13 目标接口对齐设计，并完成局部工程 canary，检查模型、梯度和读出链路。

## 当前可核实状态

以[2026-08-09 证据状态文件][status]为准：

| 项目 | 已有证据 | 可以支持的判断 |
|---|---|---|
| R10 | 无模型开发诊断与审计文件 | 原统一解释被否决；不能推出新机制普遍成立 |
| R13 canary | 1 次模型加载、16 次 forward、14 次 backward、1 次手动参数步 | 局部执行链路可运行；科学 source/target 单元均为 0 |
| R13 科学批次 | 0/8 个进程完成，无科学结果包 | 尚无 R13 正／负科学结论 |
| 协议与验证器 | 清单、hash、运行约束、分析与检查代码 | 工程／来源证据，不能替代模型实验 |

## 作品集中的价值

这一项目展示如何把研究问题拆成受控比较、如何区分软件验证与科学证据，以及发现反例后如何停止旧假设。适合作为研究工程补充，不写成 RLVR 完整训练成功、部署风险已被证明或论文已经发表。

[公开证据仓库][repo]包含经过整理的代码与文档；模型权重、第三方 PDF 及完整生成资产不在仓库中。代码阅读顺序和环境约束见[代码入口](CODE.md)。
