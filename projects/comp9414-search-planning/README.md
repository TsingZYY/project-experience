## 项目目标与工作

通过小型配送场景理解图搜索与符号规划：将位置、边和代价转成搜索问题；观察不同frontier策略如何影响路径与扩展；再用事实、前置条件和效果描述规划状态变化。

本地工作包含搜索实现、结果记录、可视化、启发式比较、规划建模与计划诊断，并整理了讨论准备材料。作品集重点展示这些能力之间的联系。
