## 依赖条件

该文件依赖原课程PostgreSQL schema及数据，不能单独在空数据库中完整运行。需要通过合法途径取得对应课程数据库和使用权限。

在自己已准备好的数据库中加载SQL会创建或替换同名视图／函数。因此应使用专门的学习数据库，并先确认已有对象不会被意外覆盖。本作品集不提供数据库安装、数据下载或自动执行脚本。
