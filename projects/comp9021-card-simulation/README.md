## 项目内容

实现两套纸牌游戏的状态转换和命令行展示，并提供批量模拟接口。第一套关注多轮发牌和牌面移除，第二套维护多组目标牌堆、可放置条件及回合日志。

两个程序都使用显式随机种子，并提供 `simulate(n, i)`：从种子 i 开始模拟 n 局，输出结果的相对频率。第二套程序还支持按行号或范围查看收集的日志。
