# 技术笔记

## 状态与展示

卡牌以整数表示，通过整除和取余确定花色与牌点，再转换为 Unicode 字符。游戏逻辑使用列表和牌堆状态，输出函数将这些状态转换为用户可读的行。

第一套程序包含面向批量模拟的计数路径和面向交互展示的回合路径；第二套将一局输出收集到列表，再让用户选择要查看的范围。两种组织方式分别服务于少输出统计和详细过程观察。

## 可复现的随机过程

代码在洗牌前显式设置 seed。`simulate(n, i)` 使用从 i 开始的连续种子，便于回到某一局检查行为。复现时仍应记录 Python 版本和相同代码快照，不能仅保存最终百分比。

显式 seed 只控制随机过程，不代表运行结果已经被独立验证，也不证明模拟样本覆盖全部可能牌序。

## 统计接口

- 第一套按移除的目标牌数量累计频次。
- 第二套按结束时剩余牌数累计频次。
- 两者将计数除以模拟局数并格式化为百分比。

这些函数打印统计表，而不是返回结构化分析对象。当前代码没有置信区间或收敛诊断，也没有把样本频率提升为理论概率。

## 日志查询

第二套程序区分退出、正／负行号及范围请求。解析与显示函数分离，有助于将输入格式问题与游戏状态问题分别定位。

## 当前边界

- 终端需要能够显示 Unicode 扑克牌；程序在支持时将标准输出设为 UTF-8。
- 随机数使用模块级 `seed`，会影响同一进程共享的随机状态。
- 全量日志会随一局过程增长，不是流式日志服务。
- 本次没有实测不同输入、模拟速度、概率稳定性或跨 Python 版本行为。
